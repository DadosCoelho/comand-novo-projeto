# Referências

## Documentação oficial

- Documentação oficial do Git: https://git-scm.com/doc
- Manual embutido de qualquer subcomando: `git help <comando>` ou
  `git <comando> --help` (abre a página man localmente).
- Referência rápida de todos os comandos: https://git-scm.com/docs

## Livros

- ***Pro Git*** (Scott Chacon & Ben Straub) — o livro de referência mais
  completo, gratuito, cobre desde o básico até internals. Disponível em
  vários idiomas, incluindo português: https://git-scm.com/book

## Aprendizado interativo

- **Learn Git Branching** — visualização interativa de branch/merge/rebase
  no navegador, muito bom para internalizar o modelo mental de grafo de
  commits: https://learngitbranching.js.org

## Ferramentas mencionadas nesta pesquisa

- **git filter-repo** — reescrita de histórico (remoção de segredos,
  extração de subpastas), recomendada oficialmente hoje no lugar do antigo
  `git filter-branch`: https://github.com/newren/git-filter-repo
- **BFG Repo-Cleaner** — alternativa mais simples/rápida para limpar
  segredos/arquivos grandes do histórico: https://rtyley.github.io/bfg-repo-cleaner/
- **gitleaks** / **git-secrets** — detecção de segredos antes do commit.
- **Husky** — versiona hooks do Git via `package.json`, no ecossistema
  Node.js.
- **Conventional Commits** — especificação de mensagens de commit
  estruturadas: https://www.conventionalcommits.org/
